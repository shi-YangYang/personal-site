# Decision: HeroUI

Date: 2026-11-13
Status: Accepted

## Decision

- Use `@heroui/react` 3.x with Tailwind CSS 4.
- Map HeroUI tokens to the cyber-green theme.
- Use HeroUI for buttons, inputs, textareas, selects, switches, and admin tabs.
- Keep the custom Hero, terminal, 3D, and visual section shells.

## Why

HeroUI supports React 19 and Tailwind 4, improves accessibility, and removes maintenance of basic primitives while preserving the site identity.

## Impact

- Adds `@heroui/react` and `@heroui/styles`.
- HeroUI CSS is imported once in `app/globals.css`.
- New interactive controls should use HeroUI.
